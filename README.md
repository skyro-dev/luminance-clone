# Luminance Labs Clone

A Vercel-inspired dark theme clone of the Luminance Labs website.

## Versions

### v1 - Direct Implementation (`website/`)
Built directly with custom CSS and components.

### v2 - Dev Crew Implementation (`website-fresh/`)
Built by the Frontend Dev agent using the dev crew workflow.

## Design
- Dark theme (pure black background)
- Glassmorphism cards
- Gradient text headlines
- Glow effects on hover
- Terminal window in hero
- Floating orbs animation

## Tech Stack
- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Lucide React icons
- Pure CSS animations (no Framer Motion)
